# 实验三：宏功能模块的使用（PLL + FIFO + UART 接收）

**目标板：Terasic DE10-Standard（Cyclone V SoC 5CSXFC6D6F31C6）。** 本工程实现实验指导书全部基本要求，并已用本机 Quartus II 13.1 完成全编译、用 ModelSim 完成自校验仿真。电脑串口发送字符 → FPGA 的 UART 接收并写入 FIFO 宏模块 → FIFO 达到半满后数码管逐一显示缓存字符 → 拨动开关切换两种显示周期。

已验证状态（本文件底部有记录）：Quartus 全编译 0 错误；ModelSim 仿真 PASS（半满触发、顺序读出、双周期切换）。

## 一、设计概览

```
PC(串口助手 115200-8N1)
   │ USB 转 TTL 转接器：绿色 TX ──杜邦线──> JP1 第 1 针 GPIO_D0 (W15) = UART_RX
   │ 黑色 GND ──杜邦线──> J15(ADC 2x5 头) 第 10 针 GND（必须共地）
   ▼
uart_rx (115200 8N-1 接收, 中点采样)
   ▼ rx_done 脉冲 + rx_data[7:0]
fifo_buf (scfifo 宏模块: 8bit × 32 字, 半满阈值 16) ──半满 almost_full──┐
   ▼ q[7:0] (每周期读一个)                                             ▼
seg7_ascii → HEX0 当前字符     显示控制 FSM (半满启动 / 读空停止)
seg7_hex   → HEX1/HEX2 剩余字数(十六进制)                    sw_period(SW0) 选周期
LEDR0 半满  LEDR1 显示中  LEDR2 空  LEDR3 满  LEDR4 系统正常
                    ▲
pll_sys (altpll 宏模块): PIN_AF14 50MHz → c0=50MHz 主时钟, c1=100MHz 备用
```

**显示周期**（拨动开关 SW0，板上的第一个拨动开关）：

| SW0 | 显示周期 | 说明 |
|---|---|---|
| 0（朝板边） | 1.0 s | 慢速 |
| 1（朝板内） | 0.25 s | 快速 |

数码管含义：
- **HEX0**：当前正在显示的 FIFO 字符。可显示数字 0-9、字母 A-Z（少数无法显示的字符显示空白，如 M、W、X）。
- **HEX1 / HEX2**：FIFO 当前剩余字数（十六进制，HEX2 是高位 0/1）。
- **LEDR0**：半满标志（核心触发信号）；**LEDR1**：显示流程进行中；**LEDR2**：FIFO 空；**LEDR3**：FIFO 满；**LEDR4**：PLL 锁定正常（亮 = 系统时钟正常）。

## 三、宏功能模块参数（与 MegaWizard 配置一一对应）

**PLL（ALTPLL）**：输入 inclk0 = 50 MHz（inclk0_input_frequency=20000ps），NORMAL 模式，补偿 CLK0；c0 = ×1 = 50 MHz；c1 = ×2 = 100 MHz；输出 locked、areset。

**FIFO（SCFIFO，同步 FIFO）**：位宽 8 bit、深度 32 字（lpm_numwords=32）、almost_full 阈值 = 16（半满）、普通（legacy）读出模式、开启溢出/下溢检查、use_eab=ON。读写同一时钟 c0 —— 同步 FIFO 的典型用法。

注：本工程的 `pll_sys.v` / `fifo_buf.v` 是按 MegaWizard 生成的包装文件逐行等价手写的（defparam 与向导界面参数一一对应），可直接编译；报告如需向导截图，按 `ip/IP向导配置对照.md` 用向导生成一次截图即可，参数与本工程一致。

## 四、硬件接线（先断电再接线）

与实验一相同的 USB 转 TTL 线，这次是**电脑→FPGA 方向**。**DE10-Standard 的 JP1（GPIO 扩展口）40 针全是数据脚和电源脚、没有 GND 针**（官方原理图 Sheet 13 确认），因此本工程把 **JP1 第 2 针（GPIO_D1，AK2）配置成常低输出充当"虚拟地"**——两根线并排插在 JP1 顶端同一排即可（依据 DE10-Standard 官方原理图 Sheet 13；UART 接收为高阻输入，该脚电流仅微安级，安全）。

| 开发板端 | 转接器线 | 用途 |
|---|---|---|
| **JP1 第 1 针 = GPIO_D0，管脚 W15**（右边缘、SD 卡槽正下方的 2x20 长排针，丝印 JP1；**最顶端靠 SD 卡槽那一排**的左针——左列丝印 GPIO_D10/D12/D14… 自上而下递增，对应第 13/15/17… 针，顶端即第 1 针） | **绿色 TX** | 电脑发送的字符进入 FPGA 接收端 |
| **JP1 第 2 针 = GPIO_D1，管脚 AK2**（同一排、绿针右边紧挨着的那根） | **黑色 GND** | 虚拟地（FPGA 常低输出），与绿线同排相邻 |

接线示意：顶端一排从左到右 = `[绿TX] [黑GND]`，两根线并排。

**绝对禁止触碰的针脚**（接错会损坏板卡或转接器）：
- JP1 **第 11、12 针（第 6 排）= +5V**，**第 29、30 针（第 15 排）= +3.3V** —— 电源排，不要接。

备注：若不用虚拟地方案，也可把黑线接到 **J15（ADC 2x5 头）第 10 针**（左边缘红按钮正下方 2x5 插座，官方 GND；其第 1 针 VCC5 在顶端为方焊盘，禁接）。两种接法二选一即可。

白色 RX 悬空（本实验 FPGA 不向电脑发送）；红色电源线不接。

## 五、烧录与上机步骤

1. 板卡供电（电源适配器），USB-Blaster II 接电脑；USB 转 TTL 线插电脑。
2. 打开设备管理器"端口"，确认转接器 COM 号（上次实验为 **COM8**）。
3. 打开 Quartus II → `File → Open Project` → `D:\exp3_fifo_macro\exp3_fifo_macro.qpf`（路径已是纯英文，无需盘符替换脚本）。
4. `Tools → Programmer`：Hardware 选 USB-Blaster II 对应项（`DE-SoC [USB-1]` 或 `USB-BlasterII`），模式 JTAG；`Auto Detect` 后在弹出的器件列表里选 **SoC FPGA（5CSXFC6）** 那行（不是 HPS），指定 `output_files/exp3_fifo_macro.sof`，勾选 Program/Configure，Start 烧录。
5. 按一下 KEY0 复位（板上 4 个按键中的 KEY0）；**LEDR4 亮 = PLL 锁定、系统正常**。
6. 打开串口助手（SSCOM/串口精灵）：端口选转接器 COM 号，**115200、8 数据位、1 停止位、无校验**。
7. 发送 **16 个字符**（如 `0123456789ABCDEF`）：发送期间 HEX1/HEX2 上的剩余字数递增；到 16 个（半满）时 LEDR0、LEDR1 亮，HEX0 开始逐一显示缓存字符；读空后 LEDR1 灭。
8. 拨动 SW0（最左边的拨动开关），观察字符切换速度变化（1 s ↔ 0.25 s）。

可再多发字符观察：超过 16 个会继续写入（FIFO 剩余字数实时显示）；一次性发满 32 个则 LEDR3（满）亮，之后到达的字符被丢弃。


testbench 自动验证：半满触发、16 字符按先进先出顺序显示、读空停止、快周期间隔约 502 周期。终端打印 `PASS` 即全部通过。GUI 方式：`vsim -do simulate.do` 后 `add wave sim:/tb_fifo_macro_top/dut/*`。

两个仿真细节（脚本已处理好，仅供了解）：
- `-L altera_mf_ver`：ASE 中 Verilog 版宏模块库的库名（`altera_mf` 是 VHDL 版）。
- `+define+SIM_PLL_IV`：ASE 10.1d 的 Cyclone V 通用 PLL 行为模型不输出时钟，仿真时切到 Cyclone IV E 行为模型；该宏只影响仿真，综合仍按 Cyclone V。

## 七、常见故障排查

| 现象 | 排查 |
|---|---|
| LEDR4 不亮 | PLL 未锁定：确认烧录成功、KEY0 复位过 |
| 发送字符 HEX1 字数不增 | 黑线是否插在 JP1 第 2 针（虚拟地）；绿线是否第 1 针；两针是否插反（对调即可）；串口助手波特率是否 115200 |
| 收到乱码 | 波特率不匹配、杜邦线接触不良 |
| 半满了但不显示 | 本工程已含该逻辑，若改动代码后出现：检查 almost_full、rdreq、显示 FSM |
| 切换开关无反应 | SW0 = AB30（最左边那个拨动开关，丝印 SW0） |
| 找不到 COM 口 | 上次配套转接线用 PL23XX 驱动（实验一时已装好） |
| 插到 JP1 后板子异常/冒烟风险 | 立即断电——检查是否误接了 JP1 第 6 排（+5V）或第 15 排（+3.3V） |

## 八、实验报告要点（对照指导书第九节）

1. 原理简述 + 半满标志作用：本工程 scfifo `almost_full` 阈值=16（深度一半）。
2. 截图来源：`ip/IP向导配置对照.md` 的向导步骤截图（PLL、FIFO 配置页）；`rtl/fifo_macro_top.v` 顶层例化代码；`exp3_fifo_macro.qsf` 管脚约束。
3. 现象截图：串口助手发送 16 字符；半满触发后 HEX0 字符变化（拍两张：SW0=0 与 SW0=1 不同时刻的字符）；HEX1/HEX2 剩余字数递增过程。
4. 问题与解决：可写"指导书 PIN_V11 与 DE1-SoC 实际不符，本板 50MHz 在 AF14"以及共地问题（上实验一记录）。
5. FIFO 缓存优势与同步 FIFO 注意事项：注意读写同一时钟、legacy 模式下 q 在 rdreq 后一拍有效（本工程 rd_dly 二拍捕获即是处理这个时序）、sclr 清空、满时写入被丢弃（overflow_checking）。
